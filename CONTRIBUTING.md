# Guia de Contribuição: Meow-Docs

Este repositório armazena artefatos textuais, diagramas, atas de reuniões e planejamentos para o projeto Meowdoku.

---

## 1. Padrões de Documentação

- Formato padrão: Markdown com sintaxe GitHub Flavored Markdown (GFM).
- Diagramas: devem ser escritos em blocos `mermaid` ou armazenados como imagens na pasta `docs/`.
- Tom de escrita: direto, técnico e impessoal. Não utilize jargões desnecessários ou elementos visuais decorativos.

---

## 2. Fluxo de Atualização

1. Ao realizar decisões em reuniões, registre a ata correspondente em `atas_reuniao.md`.
2. Alterações nas regras ou especificações do jogo devem ser refletidas de imediato em `regras_do_jogo.md`.
3. Atualizações na matriz de integrantes ou atribuições de arquivos devem sincronizar com `divisao_de_papeis.md` e a Seção 10 do `RELATORIO.md` no repositório de código.
